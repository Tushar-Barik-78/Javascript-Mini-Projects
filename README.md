# 🚀 Javascript Mini Projects

A collection of fun and beginner-friendly JavaScript mini projects built using **HTML**, **CSS**, and **Vanilla JavaScript**. Each project is self-contained and focuses on a specific concept or feature of the web.

---

## 📁 Projects Overview

| # | Project | Description |
|---|---------|-------------|
| 1 | 🎨 Color Gradient | Dynamically generate and display beautiful color gradients with button controls |
| 2 | 😂 Dad Jokes | Fetches random dad jokes from an API and displays them with a clean UI |
| 3 | ⏳ Death Clock | A 100-year clock wheel that counts time from a given birth date — visualized in a unique circular dial layout |
| 4 | ⏱️ My StopWatch | A fully functional stopwatch with start, stop, and reset functionality |
| 5 | 🕐 My Clock | A real-time digital clock displaying the current time |
| 6 | ❌⭕ Tic-Tac-Toe | A 2-player Tic-Tac-Toe game with win detection, draw handling, and turn display |
| 7 | ✅ Todo List | A simple and stylish Todo app to add, check, and manage tasks |
| 8 | 🌦️ Weather App | A weather application that fetches live weather data for any city using the OpenWeatherMap API |
| 9 | 🧪 Periodic Table | An interactive periodic table displaying chemical elements in a grid layout |

---

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layout (Flexbox, gradients, animations)
- **Vanilla JavaScript** — Logic, DOM manipulation, and API calls
- **External APIs** — OpenWeatherMap (Weather App), icanhazdadjoke (Dad Jokes)

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/Tushar-Barik-78/Javascript-Mini-Projects.git
   ```

2. **Navigate to any project folder**
   ```bash
   cd "Javascript-Mini-Projects/Tic-Tac-Toe"
   ```

3. **Open the HTML file in your browser**
   ```bash
   # Simply double-click index.html OR open via Live Server in VS Code
   ```

> ✅ No installation or build steps required — all projects run directly in the browser!

## 🌦️ Weather App — API Setup

The Weather App uses the [OpenWeatherMap API](https://openweathermap.org/api). To use it:

1. Create a free account at [openweathermap.org](https://openweathermap.org)
2. Generate your API key
3. Replace the `apiID` value in `Weather App/index.js` with your key:
   ```js
   const apiID = "YOUR_API_KEY_HERE";
   ```

## 📸 Projects Preview

### 🎨 Color Gradient
Generates smooth linear gradients with custom colors on button click.

### 😂 Dad Jokes
Fetches a new random joke every time you click the button — powered by the icanhazdadjoke API.

### ⏳ Death Clock
A mesmerizing 100-year wheel clock that visualizes years, months, days, hours, minutes, and seconds simultaneously from a set date.

### ❌⭕ Tic-Tac-Toe
Full 2-player game with:
- Random first-turn selection
- Win pattern detection (rows, columns, diagonals)
- Draw detection
- Reset and New Game buttons

### ✅ Todo List
- Add new tasks
- Mark tasks as complete with visual checkbox
- Clean gradient UI
